## Opponent Rating Scale

HT Coach team ratings calculated from players use the internal contribution scale.
Opponent ratings imported from Hattrick can use Hattrick decimal values.

Alpha 0.5.4.1 keeps both scales visible in the desktop Match results and does not
convert between them. The app only calculates a direct sector advantage when both
values share the same source scale; otherwise it displays both raw values and marks
the comparison as not directly comparable.
